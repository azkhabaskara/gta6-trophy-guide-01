Platinum Road is an offline GTA VI trophy guide and tracker for all 55 PlayStation 5 trophies: a checklist saved in your browser with progress counters per grade and PSN targets, a five-stage roadmap to the platinum, a missables page flagging the one trophy you can miss, a guide in our own words with its sources for every trophy, a spoiler setting that hides story trophies until earned, text search and filters by grade and kind, a Next up planner, light and dark themes, and export/import of your progress — all as static files that work with the network off.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
